Distribuidora: landing pública (Home, Catálogo, Detalles, Carrito, Contacto), Login y gestor privado.

## Cómo levantarlo

cd Proyecto-software-2/frontend
npm install
npm run dev

Abrir http://localhost:5173

## En otra terminal levantar el backend

cd Proyecto-software-2/backend
npm install
npm run dev
